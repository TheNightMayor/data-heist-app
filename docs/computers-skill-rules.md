# Computers Skill Rules

Reference notes for the Computers skill in Starfinder 1e. These are paraphrased summaries, not replacement rule text.

## Official reference

- [AONSRD Computers Skill](https://www.aonsrd.com/Skills.aspx?ItemName=Computers)
- Source: Starfinder Core Rulebook, pages 137–139

## General rules

- Computers is trained-only for ordinary skill use.
- The base DC for many Computers tasks is `13 + (4 x computer tier)`, adjusted by the GM when appropriate.

## Access and hacking

- Accessing an unsecured public computer is generally DC 10.
- An untrained character can attempt to access an unsecured system by taking 20; this takes 2 minutes.
- Hacking a system normally takes one full action per computer tier.
- A hacker can increase the DC by 5 to halve the hacking time, to a minimum of one full action.
- A successful hack grants access to system portions that are not behind a firewall.
- Each firewall protecting a section requires an additional Computers check.

## Fake Shell detection

- A user with computer access but without root access may actually be interacting with a Fake Shell.
- Detecting a Fake Shell takes a full action.
- The detection DC is the system's hacking DC plus 5.

## Modules and countermeasures

- With root access, disabling or manipulating a module or countermeasure is generally a standard action at DC 10.
- With ordinary access but not root access, activating, adding, disabling, or manipulating a module or countermeasure generally uses the system's hacking DC.
- A module or countermeasure behind a firewall cannot be affected until the firewall is hacked.
- Adding or removing a module generally takes 1 minute per computer tier.
- A character cannot take 20 on a Computers check to disable or manipulate a module.

## Root access

- Gaining root access works similarly to hacking the system, but at DC + 20.
- Some systems may make root access impossible.
- A firewall with a separate authorized-user list may require root access to be gained separately.

## Destroying or repairing systems

- Destroying a removed or disabled system or repairing a disabled system or module takes 10 minutes per computer tier.
- Failing the repair check by 5 or more accidentally destroys the system or module.
- A character cannot take 20 on a Computers check to destroy or repair a system.

## App mapping notes

- The current Resolve action abstracts the skill's full-action timing.
- Fake Shell should use a distinct detection action at system DC + 5 when detailed interaction is implemented.
- Firewall targets should require a separate access check for each firewall in a detailed rules mode.
- Root access should enable module and countermeasure manipulation; ordinary access should not imply root access.
